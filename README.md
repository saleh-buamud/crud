# 🚀 JavaScript CRUD Projects

A collection of practical JavaScript CRUD projects built while learning and applying modern JavaScript concepts.

The project currently contains two CRUD implementations:

- **CRUD LocalStorage** — Product Management System
- **CRUD API** — Posts Management System using Axios and JSONPlaceholder

---

# 📦 Project Overview

This project demonstrates how CRUD applications can be built using JavaScript in two different approaches.

### CRUD LocalStorage

A product management application that stores data directly in the browser using `localStorage`.

### CRUD API

A Posts management application that communicates with a REST API using Axios.

The API project supports retrieving, adding, updating, deleting, searching, sorting, and paginating posts.
